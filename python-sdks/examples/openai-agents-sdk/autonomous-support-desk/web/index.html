Autonomous Support Desk

One agent platform, two tenants, run concurrently. Each ticket is handled by a single autonomous agent on the OpenAI Agents SDK - it decides per ticket whether to search the KB, look up an order, refund, resolve, or hand off to a billing specialist. Every decision is a tool call, every call routes through the Respan gateway, and each ticket becomes one nested trace. Each step below is tagged with the Respan service it uses.
